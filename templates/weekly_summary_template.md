# Weekly summary template

## Purpose

Produce a **single weekly note** that captures the arc of the week: what moved, what stalled, and what you want next week to emphasize—optionally with help from Note Companion.

## Inputs

- Daily notes or daily process outputs for the week.
- Optional: one prior weekly summary for continuity.

## Expected outputs

- One page (or section) with: **summary**, **highlights**, **challenges**, **next week focus** (small set).
- Explicit label if any block is **AI-assisted**.

## Draft prompt / instructions

```text
Using only the daily material I provide:
Write a weekly summary in four parts:
1) Week in 5 bullets (facts from my notes only).
2) 3 highlights I'm likely to care about.
3) 3 challenges or open loops still present.
4) Next week: 3 focus areas, each one sentence, tied to my notes.
Do not add goals I did not imply. Use "not covered" where my notes are silent.
```

**Manual alternative:** Write each part in your own words first; optionally run a prompt only to tighten phrasing, keeping your original nearby.

## Notes / limitations

- Designed to be completable in **one sitting**; depth can grow after the habit exists.
- Folder placement and naming stay a vault decision.
